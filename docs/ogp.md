# OGP画像生成画面

## 概要

OGP画像（1200×630px）をスクリーンショットで生成するための専用画面。デバッグ画面からのみ遷移可能。

## サイズ

- **出力サイズ**: 1200 × 630px
- **アスペクト比**: 約 1.9:1
- **画面実装**: GameContainer 外に独立した固定サイズの div で実装（4:3制約を受けない）

## レイアウト


## 構成要素

背景・ロゴ・文言は季節テーマ（`src/shared/constants/season.ts`）から取得する。季節を切り替えたら OGP 画像も撮り直す（→ [game-design.md 季節テーマ](game-design.md#季節テーマ)）

### 1. 背景
- 季節テーマのタイトル背景を全面に `cover` で配置

### 2. メインロゴ
- 季節テーマのタイトルロゴを中央上部に大きく配置（高さ `60cqmin`）

### 3. OGP文言（ロゴ下）
- 季節テーマの文言（例: 秋は「パレ学の秋！」）
- 白文字、テキストシャドウで視認性確保（`8cqmin`）

### 4. 寮エンブレム
- 4寮（`emblem_wa/me/co/wh`）のアイコンを下部に横並び（`16cqmin`）

## 実装方針

- `src/app/routes/OgpScreen.tsx` として実装
- 固定サイズ `1200×630px` の div 内にレイアウト
- デバッグ画面に「OGP画像」ボタンを追加して遷移
- `settingsStore` の `screen` に `'ogp'` を追加
- スクリーンショット撮影はブラウザの DevTools またはスクリプトで行う

## スクリーンショット手順

1. デバッグ画面から「OGP画像」ボタンをクリック
2. ブラウザの画面サイズを 1200×630px に設定（DevTools）
3. スクリーンショットを撮影
4. `public/ogp.png` として保存
